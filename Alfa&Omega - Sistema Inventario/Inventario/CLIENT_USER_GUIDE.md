# Guía de Usuario para Cliente

Esta guía explica cómo usar el sistema de inventario una vez instalado.

## Inicio

1. Abrir el programa ejecutando `python main.py` o mediante el acceso directo que se haya creado.
2. Ingrese su nombre de usuario y contraseña (creadas por el administrador).
3. Verá el panel principal con las siguientes secciones:
   - **Productos**: Añadir, editar y eliminar artículos.
   - **Documentos**: Crear facturas, órdenes de compra y cotizaciones.
   - **Usuarios**: Gestione cuentas y permisos.
   - **Configuración**: Parámetros de empresa y opciones.

## Operaciones Básicas

### Agregar un Producto
1. Vaya a la pestaña "Productos".
2. Haga clic en "Nuevo".
3. Complete código, nombre, precio y cantidad.
4. Presione "Guardar".

### Realizar una Venta
1. Seleccione la pestaña "Documentos" y elija "Factura".
2. Añada productos mediante su código.
3. Verifique totales y haga clic en "Emitir".

### Consultar Inventario
- Use la barra de búsqueda en Productos para filtrar por código o nombre.
- Puede generar reportes desde el menú superior.

## Copias de Seguridad
- El sistema hace backups automáticos cada vez que se cierra.
- Los archivos se encuentran en la carpeta `backups`.
- Para restaurar un backup, contacte a soporte técnico.
