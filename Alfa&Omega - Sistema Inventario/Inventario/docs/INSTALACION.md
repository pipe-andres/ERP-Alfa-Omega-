# Instalación Alfa & Omega ERP

## Requisitos
- Windows 10/11 (64-bit)
- Python 3.11 o superior
- 4GB RAM mínimo
- 2GB espacio en disco

## Pasos
1. Instalar Python desde python.org
2. Descomprimir el archivo del sistema
3. Ejecutar: `py tools/instalar_cliente.py`
4. Ingresar contraseña del administrador
5. Pegar la licencia recibida
6. ¡Listo! El sistema está instalado

## Primer inicio
- Doble clic en el acceso directo del escritorio
- Usuario: `admin`
- Contraseña: la que ingresaste en la instalación
