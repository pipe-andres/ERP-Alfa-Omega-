# Guía de Pruebas — Alfa & Omega ERP
**Para: Cliente Beta · Tienda de Ropa**

## Tu misión
Probar el sistema durante 1 semana y reportar:
- ¿Qué funciona bien?
- ¿Qué es confuso o difícil de usar?
- ¿Qué le falta para tu negocio?

## Pruebas que debes hacer

### Día 1 — Inventario
[ ] Abre el sistema con usuario: admin, clave: admin123
[ ] Busca el producto "Jean Slim Fit Hombre"
[ ] Edita el precio a $125.000
[ ] Agrega un producto nuevo de tu tienda
[ ] Exporta el inventario a Excel

### Día 2 — Ventas (POS)
[ ] Abre la caja con $200.000 iniciales
[ ] Registra una venta de 2 productos
[ ] Cobra con $300.000 y verifica el cambio
[ ] Registra otra venta a crédito a "María Rodríguez"
[ ] Cierra la caja y verifica el arqueo

### Día 3 — Clientes
[ ] Busca a "María Rodríguez" en CRM
[ ] Verifica que aparece la venta del día 2
[ ] Agrega un cliente nuevo de tu tienda
[ ] Exporta la lista de clientes a Excel

### Día 4 — Compras
[ ] Crea una orden de compra a "Confecciones del Valle"
[ ] Agrega 3 productos con cantidades
[ ] Confirma la recepción parcial
[ ] Verifica que el stock se actualizó

### Día 5 — Reportes
[ ] Abre Reportes Avanzados (F6)
[ ] Revisa el P&L de la semana
[ ] Abre Inteligencia de Negocio (F9)
[ ] Genera sugerencias de precios
[ ] Exporta un reporte a Excel

### Día 6 — Finanzas
[ ] Abre Finanzas (F8)
[ ] Verifica las cuentas por cobrar
[ ] Revisa el flujo de caja
[ ] Exporta CxC a Excel

### Día 7 — Feedback
Responde estas preguntas:

1. ¿Pudiste registrar ventas sin ayuda? (Sí/No/Con dificultad)
2. ¿El sistema es rápido? (Sí/No/A veces)
3. ¿Qué fue lo más difícil de usar?
4. ¿Qué le agregarías para tu tienda de ropa?
5. ¿Lo recomendarías a otro comerciante? (Sí/No/Tal vez)
6. ¿Cuánto pagarías mensualmente por este sistema?
