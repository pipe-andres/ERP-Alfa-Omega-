### CAPA 1: JERARQUÍA VISUAL (El ojo automáticamente sabe qué importa)

**Sistema Normal (Notion competidor):**
```
┌──────────────────────────────────────┐
│ Ventas Totales: $125,400             │  ← Todo igual
│ Top 5 Productos: ...                 │  ← Usuario confundido
│ Stock Bajo: 2 items                  │  ← ¿Cuál es lo importante?
└──────────────────────────────────────┘
```

**NUESTRO SISTEMA:**
```
╔══════════════════════════════════════╗
║ Ventas Totales (pequeño, gris)       ║
║ $125,400  (32px BOLD AZUL)           ║  ← EL OJO VA AQUÍ PRIMERO
║                                      ║     (neurología visual)
║ ┌─────────────┬──────────┬────────┐ ║
║ │ Productos   │ Tend.    │ Stock  │ ║  ← Secundarios (24px)
║ │ 432         │ +12%     │ 2⚠️    │ ║
║ └─────────────┴──────────┴────────┘ ║
╚══════════════════════════════════════╝
```

**¿Por qué funciona?**
- 32px vs 14px = diferencia instantánea
- Azul PRIMARY vs Gris = contraste visual
- El ojo busca esto automáticamente (no consciente)
- Usuario ENTIENDE jerarquía sin pensar
- Resultado: **Confianza + Claridad**

---

### CAPA 2: EMPTY STATES (Fracaso → Oportunidad)

**Sistema Normal:**
```
┌─────────────────────┐
│                     │
│   No hay productos  │
│                     │
└─────────────────────┘
```
❌ Usuario siente: "El sistema está vacío. Fracasé."

**NUESTRO SISTEMA:**
```
┌──────────────────────────────────────┐
│                                      │
│            📦                        │  ← Icono amable
│  Sin productos aún                  │  ← Esperanza ("AÚN")
│  Crea tu primer producto y           │
│  verás la magia suceder             │  ← Emoción, no técnico
│                                      │
│  [✨ Crear primer producto]         │  ← CTA clara, no invasiva
│                                      │
└──────────────────────────────────────┘
```
✅ Usuario siente: "Aquí empiezo mi imperio. Emocionante."

**El copy que hace la diferencia:**
- "Sin productos AÚN" = esperanza
- "verás la magia suceder" = aspiración
- "✨ Crear primer..." = joy
- Timeout: None (no desaparece, invita a actuar)

---

### CAPA 3: BRAND VOICE (Sistema que entiende, no que ordena)

**Sistema Normal:**
```
❌ ERROR: STOCK_INSUFICIENTE
❌ [OK]
```
Robótico. Usuario asustado. Culpable.

**NUESTRO SISTEMA:**
```
┌────────────────────────────────────────┐
│ ⚠️ Stock insuficiente                  │  ← Icon comunica
│ No hay suficiente stock para           │
│ completar esta operación.              │
│                                        │
│ Stock disponible: 12 unidades          │  ← Solución integrada
│                                        │
│ Tip: Puedes ajustar cantidad o        │  ← Educativo
│      procesar cuando llegue restock    │
└────────────────────────────────────────┘
```
✅ Usuario siente: "Entiendo. El sistema me guía."

**Catálogo de Voice:**
- Errores: "Aquí está el problema + solución" (no "ERROR")
- Confirmaciones: "✅ Guardado" (no "OK GUARDADO")
- Loading: "Trayendo tu información..." (no "Cargando...")
- Focus: Hints amables (no validación futura)
- Disabled: Elegant (no sad gray)

---

### CAPA 4: DETALLES INVISIBLES (Lo que se SIENTE)

**Estos no se ven, pero se SIENTEN:**

1. **Focus State**
   - Campo seleccionado: Border azul suave + halo
   - Hint amable debajo: "Ej: Eau de Parfum Premium"
   - Usuario siente: "El sistema me guía, no me juzga"

2. **Disabled State**
   - No disponible: Gris elegante (opacity 50%)
   - Cursor: "not-allowed"
   - Usuario siente: "No roto, solo no disponible ahora"

3. **Confirmaciones**
   - Aparecen abajo derecha
   - Se cierran automáticas (2-3 segundos)
   - No invasivas, no ignorables
   - Usuario siente: "Feedback real, control real"

4. **Jerarquía en Tablas**
   - Columnas importantes: BOLD
   - Columnas secundarias: Normal
   - Detalles: Gris suave
   - Usuario siente: "Sé qué columna importa"
